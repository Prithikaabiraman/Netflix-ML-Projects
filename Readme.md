# Netflix Machine Learning Projects

A collection of machine learning projects built using Python, Pandas, Scikit-learn, and K-Nearest Neighbors (KNN).

These projects use a Netflix content dataset to explore different machine learning tasks, including classification, prediction, recommendation, and similarity-based analysis.

## Projects

### 1. Movie vs TV Show Prediction

Predicts whether a Netflix title is a **Movie** or **TV Show** using selected numerical features.

### 2. Genre Prediction

Uses machine learning to predict the **genre** of a Netflix title based on available features.

### 3. Movie Recommendation System

Recommends movies with similar characteristics using a **Nearest Neighbors** approach.

### 4. Popularity Prediction

Predicts whether a title is **Popular** or **Not Popular** based on its features and view count.

## Dataset

The projects use a Netflix content dataset provided for the machine learning training project.

The dataset contains information such as:

* Show ID
* Title
* Type
* Release Year
* Genre
* Country
* Rating
* Duration
* Views

## Purpose

The purpose of this repository is to practice applying machine learning concepts to a real-world-style dataset and understand how different algorithms can be used for prediction, and recommendation-based problems.

## How to Run

1. Download or clone this repository.
2. Open the required `.ipynb` file in Jupyter Notebook or JupyterLab.
3. Make sure the required Python libraries are installed.
4. Run the notebook cells from top to bottom.
